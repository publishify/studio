# ADR-0007: The editorial board never changes the text

- **Status:** accepted
- **Date:** 2026-11-06

## Decision
No agent, tool or MCP call rewrites, lengthens or shortens the author's text. The board only produces notes, observations and suggestions. Objective checks (consistency, sources, file validity) give pass/fail; subjective assessments (story strength, voice, impact) never deliver a verdict of "not ready to publish".

## Consequences
This is the product's promise of trust and its point of difference from competitors (OpenWriter, Sudowrite). "Rewrite / extend / fill in" features are never added.
