# ADR-0002: Arayüz React + TypeScript + Vite

- **Durum:** kabul edildi
- **Tarih:** 2026-11-06

## Bağlam
Tek kişilik, yapay zekâ destekli geliştirme; ileride ekip büyüyebilir.

## Karar
React + TypeScript (strict) + Vite + Tailwind CSS.

## Değerlendirilen seçenekler
- Svelte 5 — daha küçük paket, daha az ekosistem; yapay zekâ üretiminde daha az örnek.
- Next.js — editör tarayıcıda çalışan, çevrimdışı bir uygulama; sunucu tarafı oluşturma burada fayda sağlamıyor. Siteler (tanıtım, CMS) için ayrıca kullanılacak (vinext).

## Sonuçlar
Yaygın ekosistem, kolay işe alım; Svelte'e göre biraz daha büyük paket.
